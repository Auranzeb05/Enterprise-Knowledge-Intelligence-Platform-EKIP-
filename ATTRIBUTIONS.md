# Open Source Acknowledgments

EKIP uses open-source libraries and frameworks across its frontend and backend.

Major dependencies include:

- React
- Vite
- Tailwind CSS
- Radix UI
- Material UI
- Recharts
- Lucide
- Express
- Prisma
- Supabase JavaScript client
- Vitest
- Ollama

Each dependency remains subject to its own license and attribution requirements. Refer to the corresponding package metadata and upstream projects for complete licensing information.
