# Open Source Acknowledgments & Credits

This frontend architecture for EKIP 1 leverages industry-standard open-source primitives and modern design systems to ensure high performance, accessibility, and clean visual structures.

## Component Architecture & Primitives
* **Radix UI Primitives:** Used to implement fully accessible, unstyled foundation structures (including Accordions, Dialogs, Dropdowns, and Popovers) ensuring maximum compliance with standard keyboard navigation models.
* **Material UI (MUI):** Icons and system components utilized under standard open-source parameters to maintain crisp, pixel-perfect layout interfaces across modern devices.

## Design Framework Integration
* Core interface colors, spacing systems, and custom tokens are managed cleanly via Tailwind CSS v4 directives inside our centralized styling sheets.
* High-definition media, icons, and asset layers are structured using custom vector graphics mapped directly to the interactive user paths.

## Code Standards
All custom code modifications, fallback layout blocks (such as our customized `ImageWithFallback` component), and component compositions have been manually engineered and refactored for optimized production builds.
