# EKIP 1 - Enterprise Authentication Portal

A secure, modern frontend login portal built for enterprise cloud environments. This system features robust component styling, fluid micro-interactions, and a responsive portal layout.

## Tech Stack
* **Framework:** React 18 (Vite)
* **Styling:** Tailwind CSS v4 & custom tokens
* **Components:** Radix UI primitives & Material UI icons
* **Animations:** Motion (Framer Motion)
